⏱️ 專案實裝與除錯時間軸 (Engineering Timeline)

🎯 階段 1：雙引擎架構定調與「方案 C」語言探測實作
2026-09-27 16:30
架構決策 Breeze2 vs Whisper 方案 C 探測

為了解決單一模型「繁中俚語標點不自然」與「國際英語詞彙辨識吃力」的互斥困境，專案團隊決定引入雙模型：台灣中研院聯發科開源特化的 Breeze2-Whisper 與多國語言通用的 faster-whisper (CTranslate2)。

💡 方案 C 語言探測混合機制
優先透過 yt-dlp --dump-json 解析標題與字幕中繼資料。若標題語意不明或為純代碼，則以 Range Request / ffmpeg 高速抓取前 15 秒短音訊進行語音特徵快篩。同時提供 5 秒倒數計時，允許使用者按下 [e] 或 [z] 手動覆寫。
⚡ 階段 2：Colab 原生直連架構與 Google AI Pro GPU 調度
2026-09-27 18:20
Google Colab Control Plane L4 / T4 自動降級 Heartbeat 保活

徹底拋棄傳統 WebUI 與第三方 ngrok / Cloudflare Tunnel 跳板。直接利用 google-colab-cli 原生走 Google Colab Control Plane API 與 Jupyter Kernel WebSocket (WSS) 進行通道通訊。

🛡️ 算力點數止血保護
算力排程策略：優先租賃 L4 GPU (24GB VRAM)，遭遇配額限制或 400 錯誤時自動降級至 T4 GPU (16GB VRAM)。執行前執行孤兒會話巡檢，執行後無論成功或失敗均觸發 colab stop，達成「0 殭屍 VM」的點數防燃燒承諾。
🔥 階段 3：遭遇 YouTube 機房 IP Bot 風控挫折與自適應救援突圍
2026-09-27 21:10
重大攻防 自適應雙軌機制 無感直傳救援

在針對長達 61 分鐘的 MIT YouTube 演講（hy8UstR2NEg）進行雲端轉錄時，遠端 Colab VM 突然拋出嚴厲的防爬警告：Sign in to confirm you're not a bot (HTTP 429)。Google 資料中心 IP 被 YouTube 列入黑名單。

🛑 傳統作法的缺點
要求使用者手動匯出 cookies.txt 或在 VM 內登入，操作繁瑣且極易失效，破壞「無人值守工業級水管」的初衷。
🚀 突破性解決方案：自適應雙軌救援 (Adaptive Fallback)
遠端轉錄腳本捕獲 Bot 異常後回傳 FALLBACK_TO_LOCAL_UPLOAD 訊號；本機 run.sh 自動接手，利用開發者本機的乾淨「家用住宅 IP」呼叫 yt-dlp 順暢抓取音訊，經 ffmpeg 標準化為 16kHz PCM16 Mono 音訊後，透過 colab upload 直傳遠端 VM 接續推論。使用者零體感障礙，管線全自動修復！

🛡️ 階段 5：Codex (GPT-6 Astra) Code Review 與安全架構重構
2026-09-27 23:20
Codex 審查 Base64 安全序列化 SHA-256 數位簽章 POSIX Trap

引入 OpenAI Codex (GPT-6 Astra 架構) 進行嚴格的靜態代碼與安全性審查，揪出多項潛在漏洞並進行全盤重構：

  • 消滅 Bash 字串拼接注入：全面廢除 Python 多行三重引號 ''' 拼接字串，改用 base64.b64encode(json.dumps(payload)) 序列化傳參，杜絕代碼注入。
  • 防偽 Manifest 數位簽章：遠端推論生成包含 SHA-256 雜湊與檔案大小的 manifest.json，下載前逐檔校驗，防止偽造與傳輸毀損。
  • 防 Path Traversal 注入：建立嚴格的檔名正規化白名單，阻斷 ../ 等目錄跳脫攻擊。
  • POSIX 訊號捕捉強化：重構 run.sh 的 trap 機制（精確捕捉 SIGINT 130、SIGTERM 143、EXIT），增加 CLEANUP_CALLED 防重複進入旗標。
💎 階段 6：Claude Code (Opus) 深度架構審查與生產級防禦封裝
2026-09-27 23:50
Claude Opus 審查 原子化同步 (Atomic Sync) 200 Bytes 限長截斷 27 項測試全綠

由 Anthropic 最強旗艦模型 Claude Opus 進行第二輪深度架構批判與邊界壓力測試，針對 5 大核心細節完成終極淬煉：

審查揪出之隱蔽缺陷 工程因果與潛在危害 Claude Opus 重構解法
快取僅檢驗檔名非空 若本機留存毀損或半截之 .srt，將導致「壞檔假命中」，錯失轉錄。 is_cache_hit() 強制調用 verify_manifest() 校驗實體 SHA-256 雜湊。
白名單誤殺標題省略號 正規化把合法影片標題的 ...（例如 Wait... what?）當作 Path Traversal 誤殺。 精修正則運算式，嚴格區隔非法路徑跳脫符與文本省略號。
超長影片標題崩潰 某些 YouTube 包含極多 Emoji 或長文本，超出 Linux ext4 255 位元組限制引發 File name too long。 在安全清理後加入 200 UTF-8 Bytes 安全長度截斷，保留副檔名安全邊界。
下載中途中斷污染良品 colab download 直接覆蓋本地 output/，若下載到一半斷線會毀損原本地檔案。 實作 Staging 暫存下載與原子替換 (Atomic Sync)，全部檔案驗證無誤才原子移動。
快取檢查前存在雲端等待 原本先執行 reconcile_orphan_sessions()，導致本地命中快取仍需等待幾秒網路請求。 將快取檢查挪至最前置，達成 真正的 0 雲端延遲秒級交付。

重構完成後，擴充 tests/test_sync_artifacts.py 與 tests/test_run_sh.py，達成 全量 27 項單元與整合測試 100% 綠燈通過！

GitHub 開源發布 Codex 資安掃描 Claude Code 資安審查 100% 零外露通過

在正式推播至公開倉庫 lushinshang/newwhisper 前，啟動紅藍隊思維之全域資安與隱私脫敏稽核，確保具備最高標準之資料保護與合規性：

  • 致謝開源原作者：在 README.md 深度致謝並引用 thc1006 開源之 breezesprint-25 與 whispersprint 兩大核心轉錄專案。
  • 全域開發者路徑脫敏：全面消滅 /Users/xxx 等本機絕對路徑，改採 os.path.expanduser 動態解析與相對路徑封裝；pyproject.toml 移除本機套件路徑，改以官方 Git 依賴管理。
  • 測試案例全面 Mock 去識別化：改造 tests/test_detect.py 與 tests/test_cache.py，消滅真實 Google Drive ID，改用虛擬 ID 與 monkeypatch 攔截網路請求；範例檔名統一重構為 sample_chinese_lecture_49min。
  • 軍規級 .gitignore 防線：嚴格覆蓋 .env*、credentials.json、service-account*.json、client_secret*.json、id_rsa*、*.pem、*.key、cookies.txt 等憑證。
  • 單一純淨 Commit 覆寫：透過 git commit --amend 與 git push --force，確保遠端 Git 歷史絕對無任何「先提交後刪除」之敏感檔案殘留。
