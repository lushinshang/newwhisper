📌 專案執行摘要 (Executive Summary)

傳統影音轉錄面臨兩大核心瓶頸：本地硬體算力瓶頸（筆電風扇狂轉、記憶體不足）以及單一轉錄模型對中英文夾雜處理的失真。 本產品打造了一個由 CLI 驅動的高韌性自動化管線，透過即時語系探測，智慧決策並分流調度至 BreezeSprint-25（台灣繁中最佳化）或 WhisperSprint（國際多語系通用），並利用 Google Colab 原生直連技術在雲端租賃 Google AI Pro GPU（L4 / T4）完成高通量推論，最後零摩擦原子化同步回本地端。

本系統已完整通過 Google Drive 49 分鐘繁中長音訊（1,194 句字幕）與 YouTube 61 分鐘英文大課（1,339 句字幕）端到端實戰驗收，並歷經 Codex (GPT-6 Astra) 與 Claude Code (Opus) 雙頂級 AI 專家代碼審查，具備 27 項單元與整合測試 100% 綠燈覆蓋。

1.2 算力配置與優先級策略 (Google AI Pro Tier)

針對使用者的 Google AI Pro 配額，建立雙軌制（TPU 極速矩陣軌 vs GPU 標準生態軌）的硬體排程矩陣：

  1. 專案支援 JAX/XLA 時之首選：TPU v5e-1 (16GB HBM) —— 享受 Google AI Pro 專屬充裕配額，矩陣乘法運算極快，轉錄成本/時間效益最高（例如 whisper-jax）。
  2. 標準 PyTorch/CUDA 之第一優先：L4 GPU (24GB VRAM) —— 具備現代 Ada Lovelace 架構，支援 FP8/FP16，Breeze2 與 Whisper 轉錄效能最高，點數消耗適中。
  3. 次級備援：T4 GPU (16GB VRAM) —— 泛用度最高、配額充足，點數消耗最低。
  4. 旗艦備援：A100 GPU (40GB/80GB) —— 僅當處理超大型音訊且配額充裕時允許升級。
  5. 保底與熔斷：CPU 降級或中斷通知 —— 若無可用 TPU/GPU 配額，主動提示使用者，避免 CPU 轉錄過久耗盡等待耐性。

💻 第三章：工程實作與可靠性規格 (Tech Lead / Dev 視角)

Dev 核心主張 極簡依賴、無感隔離、防禦性編程、冪等操作

「我們嚴格落實『Shell 主導入口、Python 負責通訊、uv 隔離環境』的黃金三角。程式碼中絕不寫死絕對路徑，所有與雲端互動的呼叫必須自帶 Retry 與 Timeout 守護神。」

3.1 技術棧與工具鏈選型

  • 入口協調器：POSIX 相容 Bash (run.sh)，無依賴啟動，具備 trap 信號精確捕捉（SIGINT 130、SIGTERM 143、EXIT 自動觸發 cleanup_vm，具備重複調用防護）。
  • 環境與套件管理器：uv (Rust-based 高速 Python 工具包)，隔離維護 google-colab-cli、yt-dlp、pytest，零全域污染。
  • 遠端通訊工具：google-colab-cli 原生整合，支援 --auth=adc 與 --auth=oauth2 直連通道。
  • 參數安全通訊架構：全面廢除三重引號字串拼接，採用 Base64 + JSON 安全序列化傳遞執行參數，徹底免疫 Bash 注入風險。
  • 防偽與完整性校驗：遠端推論完畢後即時簽署 manifest.json (SHA-256 數位雜湊)；本地 verify_manifest 逐檔驗證，杜絕損壞或殘缺假命中。
  • 檔案系統安全邊界：檔名防 Path Traversal 白名單、支援合法省略號 ...，並強制施行 200 UTF-8 Bytes 安全長度截斷，防範 Linux ext4 File name too long 崩潰。
  • 原子化同步 (Atomic Sync)：產物下載經由 .staging/ 隔離暫存，驗證成功後原子替換（Atomic Move），杜絕網路中斷污染既有良品。
  • 雙軌推論核心：
    • BreezeSprint-25：支援 Breeze2-Whisper 繁中模型，針對台灣語音語境與標點符號進行特化重構。
    • WhisperSprint：基於 faster-whisper (CTranslate2) 高通量批次轉錄，多國語言通用。

3.3 斷點續傳與恢復能力層級 (Idempotent Design)

轉錄長影音時，需嚴格區分不同層級的恢復能力邊界，避免不實的狀態持久化假設：

恢復層級 判定機制 行為與邊界
第 1 層：產物快取 本地存在 .srt 與 .txt 且通過 verify_manifest() 雜湊校驗 前置攔截，完全略過雲端算力與會話請求，0.2 秒極速交付。
第 2 層：原子傳輸續傳 下載中途斷線，遠端產物存在 重試 colab download 補抓至 .staging/，經完整 SHA-256 雜湊比對成功後方原子置換，中斷絕不污染 output/。
第 3 層：推論恢復邊界 遠端推論中斷或 VM 崩潰 不可逆邊界宣告：因 Colab /content 隨 VM 銷毀而清空，未上傳至 Drive 之暫存無法跨 VM 續推，需重新啟動推論管線。 
# 產物快取檢驗範例 (verify_manifest 雙重保證)
BASE_NAME=$(get_safe_filename "$INPUT_URL")
LOCAL_SRT="./output/${BASE_NAME}.srt"
LOCAL_TXT="./output/${BASE_NAME}.txt"

if verify_manifest "./output" "$BASE_NAME"; then
    echo "⏭️ [產物快取命中] 偵測到本地已存在轉錄成果且數位雜湊完整: $BASE_NAME"
    echo "💡 跳過雲端算力請求，0 延遲直接交付本地檔案。"
    exit 0
fi
